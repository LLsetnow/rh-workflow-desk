扫描口径

本次使用 macOS 数据卷的 df 实测容量，并用 gdu -x -B1 对用户目录进行深层递归统计；另外对 100 MB 以上目录/文件做了热点扫描。目录统计可能受 APFS 克隆、快照、硬链接和应用容器机制影响，所以“目录之和”不必等于 df 的已用值。报告不执行删除操作。
