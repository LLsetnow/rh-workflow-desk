# RH Workflow Desk 开发说明

这里是 RH Workflow Desk 的基础开发文档。它记录当前项目已经形成的界面、目录和运行约定，方便新增页面或调整样式时保持一致。

- [前端唯一风格规则](./frontend-style.md)：颜色、字体、控件、布局、导航、弹窗和动效的唯一约定。
- [应用架构与数据](./architecture.md)：页面、后端模块、本地数据和任务生命周期的关系。
- [本地开发与验证](./development.md)：启动、测试、语法检查和提交前检查清单。
- [提示词工坊翻译](./translation.md)：阿里云翻译配置、字段和英文导出规则。
- [MiniMax H3 提示词 Agent 指南](./h3-prompt-agent-guide.md)：优先复用 `ref` JSON 媒体卡片和文本积木，按 H3 规则生成提示词。
- [Telegram 成片推送](./telegram.md)：任务完成后的 Bot 推送、配置和重试规则。

## 维护规则

- `frontend-style.md` 是前端风格的唯一规则文档；公共 token 和组件实现以 `static/app.css` 为唯一代码入口。
- 先复用现有 CSS 变量、组件类名和页面结构，再新增样式。
- 只修改与需求相关的页面和数据；不要把历史任务自动登记到工作流库。
- 涉及本地文件时保存路径，不复制用户的原始输入文件；剪贴板图片是为了可复用而保存的特殊例外。
- 修改公共样式、路由或数据字段时，同步更新对应文档和测试。
